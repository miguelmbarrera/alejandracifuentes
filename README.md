# Página de perfil · Alejandra Cifuentes Cortés

Página publicada en **https://miguelmbarrera.github.io/alejandracifuentes/**, con la marca Takami.

## Cómo cambiar la información

1. Entra a github.com y abre este repositorio.
2. Haz clic en el archivo **`perfil.js`**.
3. Toca el ícono del **lápiz** (Edit this file).
4. Cambia solo el texto que está **entre comillas**. No borres comillas, comas ni corchetes.
5. Toca **Commit changes…** y luego otra vez **Commit changes**.
6. En 1 o 2 minutos la página se actualiza. Si no ves el cambio, recarga la página.

### Cambios frecuentes

| Quiero… | Qué cambio en `perfil.js` |
|---|---|
| Mostrar un botón de correo | pon el correo en `correo` |
| Mostrar un botón de WhatsApp | pon el número con 57 en `whatsapp` |
| Mostrar el botón «Conoce Takami» | pon la dirección web en `takami` |
| Cambiar la frase del encabezado | el texto de `frase` |
| Cambiar las cifras | la lista `alcance` |
| Agregar una certificación | copia una línea de `certificaciones` |

### Cambiar la foto

Sube una imagen nueva con el nombre **`foto.jpg`** (Add file → Upload files).

## Archivos

- `index.html`: diseño con la marca Takami. No hace falta tocarlo.
- `perfil.js`: toda la información. Es el único archivo que se edita.
- `foto.jpg`, `logo-blanco.png`, `logo-negro.png`, `logo-t-negro.png`: foto y logos de Takami.
